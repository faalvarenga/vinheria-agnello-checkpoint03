# Vinharia Agnello - Checkpoint 03

## Descrição
Sistema de controle de estoque da Vinharia Agnello.
Foram usados objetos, arrays e funções:

- **Array de objetos** com os vinhos (nome, tipo, safra e estoque)
- **adicionarVinho()** – adiciona um novo vinho com `push`
- **listarVinhos()** – lista todos os vinhos com `forEach`
- **vinhosEstoqueBaixo()** – mostra os vinhos com estoque abaixo de 5 usando `filter`
- **estoqueTotal()** – calcula o estoque total com `reduce`
- **nomesEmCaixaAlta()** – exibe os nomes em caixa alta com `map`

Os resultados aparecem no console do navegador (F12) e em um `alert()`.
